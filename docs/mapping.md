# Маппинг элементов СМО на сущности бизнес-домена

**Лукин Илья Алексеевич · 5130904/40101 · Вариант № 27**  
**Система:** исполнение ордеров криптовалютной биржи

| Элемент СМО | Код | Сущность бизнес-домена | Назначение |
|---|---|---|---|
| Источник 1 | ИБ, ИЗ2 | VIP-трейдеры | Крупные институциональные участники (фонды, маркет-мейкеры, банки). Подают ордера большого объёма. Наивысший приоритет. |
| Источник 2 | ИБ, ИЗ2 | Standard-трейдеры | Розничные участники рынка, сделки небольшого объёма. |
| Закон генерации | ИЗ2 | Равномерный поток ордеров | Интервал между ордерами источника *i* — U[a_i, b_i]: ровная торговая активность в течение сессии. |
| Заявка | — | Ордер трейдера | Заявка на покупку или продажу актива (BTC, ETH, USDT) с объёмом, ценой, торговой парой и меткой времени. |
| Буферная память | Д1ОЗ3 | Очередь ордеров ограниченной ёмкости *K* | Хранит ордера, ожидающие свободного движка. Новый ордер занимает первую свободную ячейку с начала буфера; указателя нет, сдвига нет. |
| Прибор 1 | ПЗ1 | Движок исполнения № 1 | Основной вычислительный модуль биржи, получает ордера в первую очередь. |
| Прибор 2 | ПЗ1 | Движок исполнения № 2 | Резервный модуль, задействуется при занятости основного. |
| Закон обслуживания | ПЗ1 | Экспоненциальное время исполнения | Большинство ордеров исполняются быстро, редкие крупные сделки — значительно дольше. |
| Обслуживание | ПЗ1 | Исполнение ордера движком | Валидация, поиск встречной заявки в order book, исполнение сделки, расчёт комиссии, обновление балансов. |
| Диспетчер постановки | Д2П1, Д1ОЗ3, Д1ОО5 | Модуль приёма ордеров системы матчинга | Алгоритм, а не человек. Выбирает свободный движок, при занятости ставит ордер в буфер, при полном буфере отклоняет. |
| Диспетчер выбора | Д2Б4 | Планировщик исполнения | При освобождении движка выбирает из буфера ордер с наименьшим номером источника (VIP раньше Standard), среди одного источника — последний поступивший. |
| Дисциплина выбора прибора | Д2П1 | Приоритет по номеру движка | Поиск свободного движка всегда начинается с движка № 1. |
| Дисциплина отказа | Д1ОО5 | Отклонение нового ордера | При полном буфере отклоняется вновь пришедший ордер любой категории с кодом `ORDER_REJECTED: queue full`; буфер не меняется. |
| Отказ | Д1ОО5 | Потерянный ордер | Ордер, отклонённый из-за перегрузки. Записывается в журнал отказов и учитывается в p_отк. |
| Выход из системы | — | Исполненный ордер | Сделка записана в историю торгов, балансы обновлены; времена ордера включаются в статистику. |
| Автоматический режим | ОР1 | Сводная таблица характеристик | p_отк, T_преб, T_БП, T_обсл, Д_БП, Д_обсл по источникам и K_исп по движкам. |
| Пошаговый режим | ОД3 | Временная диаграмма | Поступления ордеров, ожидание в буфере, заполнение ячеек, занятость движков и отказы по оси модельного времени. |

Подробности бизнес-домена: [бизнес-домен](business-domain.md). Запланированные программные классы: [первичные артефакты](primary-artifacts.md).
